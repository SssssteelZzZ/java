# Оптимизация Haier Android TV PRO — очистка от рекламы и ускорение

Проект: набор скриптов, которые через **ADB по Wi-Fi** вычищают из телевизора
предустановленный мусор, рекламу и телеметрию, а затем ускоряют интерфейс.

- **Устройство:** Haier Android TV PRO
- **Адрес отладки:** `192.168.0.149:37765`
- **Папка проекта:** `haier-tv-optimization/`
- **Ветка:** `claude/tv-wifi-debug-optimization-1v8014`

---

## ⚠️ Важно: почему я не подключился к телевизору сам

Я работаю **в облачном контейнере**, а не на твоём компьютере. Адрес
`192.168.0.149` — это частный адрес внутри **твоей домашней сети**, снаружи
он недоступен физически. Я это проверил:

```
$ timeout 6 bash -c 'cat < /dev/null > /dev/tcp/192.168.0.149/37765'
exit 124   # таймаут — маршрута до твоей сети нет
$ which adb
1          # adb в контейнере не установлен
```

Ни один облачный агент не сможет достучаться до `192.168.0.x` — для этого
нужно быть в той же Wi-Fi-сети, что и телевизор.

**Поэтому вместо ручного подключения я собрал готовый инструмент**, который
делает всю работу за один запуск с твоего компьютера (5 минут на всё, включая
установку adb). Ниже — инструкция.

## Быстрый старт

### Вариант А — Windows (проще всего)

1. Скачай [platform-tools для Windows](https://dl.google.com/android/repository/platform-tools-latest-windows.zip)
2. Распакуй архив (например в `C:\platform-tools`)
3. Положи туда файл **`tv_optimize_windows.bat`** из этого проекта
4. Запусти двойным кликом и иди по меню: **1 → 2 → 3 → 4 → 5**

### Вариант А2 — macOS, одной командой (проще всего для мака)

Открой **Терминал** (Cmd+Space → «Терминал») и вставь:

```bash
curl -fsSL -o ~/Downloads/tv.command \
  https://raw.githubusercontent.com/SssssteelZzZ/java/claude/tv-wifi-debug-optimization-1v8014/haier-tv-optimization/mac_tv_optimize.command \
  && bash ~/Downloads/tv.command
```

Скрипт `mac_tv_optimize.command` самодостаточный: сам скачает Android Platform
Tools от Google (~10 МБ, без Homebrew и без пароля администратора), проведёт
через сопряжение по коду, отключит мусор и ускорит интерфейс. Спросит только
IP, порт и код сопряжения с экрана телевизора.

Откат: `bash ~/Downloads/tv.command --restore`

> Запускай именно так — через `bash файл`, а не `curl ... | bash`. При запуске
> через конвейер скрипт не сможет прочитать твои ответы на вопросы: stdin занят
> самим конвейером.

### Вариант Б — macOS / Linux / Git Bash

```bash
# 1. Установить adb
brew install --cask android-platform-tools   # macOS
sudo apt install adb                          # Ubuntu/Debian

# 2. Перейти в папку проекта
cd haier-tv-optimization

# 3. Подключиться (потребуется код с экрана телевизора)
./01_connect_tv.sh

# 4. Посмотреть, что вообще стоит на телевизоре — ничего не меняет
./02_scan_tv.sh

# 5. Посмотреть план чистки (тоже ничего не меняет)
./03_debloat_tv.sh

# 6. Выполнить чистку (базовый мусор + Google-сервисы + реклама по шаблонам)
./03_debloat_tv.sh --apply --google --patterns

# 7. Ускорить интерфейс и включить блокировку рекламы
./04_speedup_tv.sh

# 8. Перезагрузить
adb reboot
```

## Как подключиться: два порта, а не один

Это **главная причина**, по которой у людей не получается подключиться.
На Android 11+ (а у Haier Android TV PRO именно он) беспроводная отладка
использует **два разных порта**:

| Шаг | Где взять | Порт | Команда |
|-----|-----------|------|---------|
| 1. Сопряжение (один раз) | «Подключить устройство с помощью кода подключения» — там 6-значный код и **свой** порт | меняется каждый раз | `adb pair 192.168.0.149:ПОРТ КОД` |
| 2. Подключение (каждый раз) | Главный экран «Отладка по Wi-Fi» | **37765** (твой) | `adb connect 192.168.0.149:37765` |

Окно с кодом на телевизоре **нельзя закрывать** до конца сопряжения — при
закрытии порт и код меняются.

После **перезагрузки телевизора порт `37765` меняется** — надо снова посмотреть
его на экране отладки. Сопряжение при этом сохраняется, повторять его не нужно.

## Что делает каждый файл

| Файл | Назначение |
|------|------------|
| `01_connect_tv.sh` | Сопряжение и подключение по Wi-Fi, проверка связи |
| `02_scan_tv.sh` | **Только чтение.** Инвентаризация: полный список пакетов, что из них мусор, топ пожирателей ОЗУ |
| `03_debloat_tv.sh` | Отключение/удаление рекламы и предустановленных приложений |
| `04_speedup_tv.sh` | Ускорение анимаций, блокировка рекламы через DNS, отключение фоновых задач |
| `99_restore_tv.sh` | Полный откат всего, что сделали скрипты 03 и 04 |
| `tv_packages.conf` | Списки пакетов: что защищено, что мусор, шаблоны поиска рекламы |
| `lib_common.sh` | Общие функции (подключение, проверки, цветной вывод) |
| `tv_optimize_windows.bat` | Всё то же самое одним файлом с меню, для Windows |
| `reports/` | Отчёты сканирования и **журналы для отката** — не удаляй их |

## Два режима удаления — что выбрать

| Режим | Команда | Что происходит | Откат |
|-------|---------|----------------|-------|
| **disable** (по умолчанию) | `pm disable-user --user 0` | Приложение остаётся на диске, но не запускается и пропадает из меню. Не ест ОЗУ, не лезет в сеть | `pm enable` — мгновенно |
| **uninstall** (`--uninstall`) | `pm uninstall -k --user 0` | Удаляется для пользователя, APK остаётся в системном разделе. Освобождает место | `cmd package install-existing` |

**Root не нужен ни там, ни там.** Разницы в скорости практически нет —
отключённое приложение система не запускает вообще. По умолчанию выбран
`disable` как более безопасный.

## Что именно удаляется

### 1. Предустановленные онлайн-кинотеатры (удаляются всегда)

IVI, MORE.TV, Okko, Wink, MEGOGO, Кинопоиск, START, KION, PREMIER, Триколор,
viju, Peers.TV, Лайм HD, МТС ТВ, Netflix, Prime Video, Disney+, Spotify.

Это партнёрские витрины. Они висят в фоне, тянут баннеры и рекомендации по сети.
Любое при желании ставится обратно из Google Play.

> **DREZKA, которая у тебя на главном экране, не трогается** — это твоё
> приложение, а не предустановленное.

### 2. Сервисы Google (флаг `--google`)

| Пакет | Что потеряешь |
|-------|---------------|
| `com.google.android.katniss` | Голосовой поиск и Ассистент — **самый прожорливый фоновый процесс** |
| `com.google.android.tvrecommendations` | Рекламные строки рекомендаций на главном экране |
| `com.google.android.play.games` | Каталог игр Play |
| `com.google.android.videos` | Витрина платного кино Google TV |
| `com.google.android.apps.tachyon` | Видеозвонки Meet/Duo |
| `com.google.android.backuptransport` | Бэкап настроек в облако |
| `com.google.android.marvin.talkback` | Озвучка для незрячих |
| `com.google.android.syncadapters.*` | Синхронизация контактов и календаря |

### 3. Реклама и телеметрия по шаблонам (флаг `--patterns`)

Автопоиск по всему списку пакетов: `.ads`, `adservice`, `advertis`, `analytics`,
`telemetry`, `.tracker`, скрытые стабы Facebook, `retailmode` (режим витрины
магазина), демо-приложения. Скрипт показывает находки **и спрашивает
подтверждение** — потому что у каждой прошивки свой набор.

### 4. Что не тронется никогда

Защищённый список в `tv_packages.conf`: ядро Android, SystemUI, настройки,
лаунчеры, Play Store и Google Play Services, WebView, Wi-Fi и Bluetooth,
**сервис пульта**, экранная клавиатура, драйверы чипсета (MediaTek/Amlogic)
и вендорные службы Haier (панель, тюнер, HDMI).

Даже если шаблон случайно поймает такой пакет — он будет отброшен на последнем
шаге. Это защита от «кирпича».

## Что делает ускорение (скрипт 04)

| Настройка | Значение | Зачем |
|-----------|----------|-------|
| `window_animation_scale` | `0.5` | Android по умолчанию рисует переходы 300–400 мс. Это не тормоза, а заложенная задержка — **самый заметный на глаз прирост** |
| `transition_animation_scale` | `0.5` | То же для переходов между экранами |
| `animator_duration_scale` | `0.5` | То же внутри приложений |
| `private_dns_mode` + `private_dns_specifier` | `dns.adguard-dns.com` | **Главный анти-рекламный приём.** Рекламные домены не резолвятся → баннеры не грузятся ни в одном приложении, включая неудаляемые |
| `limit_ad_tracking` | `1` | Запрет таргетинга по рекламному ID |
| `send_action_app_error` | `0` | Не отправлять отчёты о падениях |
| `wifi_scan_always_enabled` | `0` | Телевизор стоит на месте — постоянный поиск сетей не нужен |
| `ble_scan_always_enabled` | `0` | То же для Bluetooth |
| `cached_apps_freezer` | `enabled` | Приложения в фоне перестают получать процессорное время (Android 11+) |
| `network_recommendations_enabled` | `0` | Не опрашивать «рекомендованные сети» |

### Дополнительные флаги

```bash
./04_speedup_tv.sh --no-anim       # анимации полностью в 0 (ещё быстрее)
./04_speedup_tv.sh --aggressive    # ограничить фоновые процессы (для ТВ с 1.5-2 ГБ ОЗУ)
./04_speedup_tv.sh --compile       # AOT-перекомпиляция всех приложений
./04_speedup_tv.sh --dns=security.cloudflare-dns.com   # другой DNS
./04_speedup_tv.sh --no-dns        # не трогать DNS
```

**`--compile`** прогоняет `cmd package compile -m speed -a`: все приложения
перекомпилируются в машинный код, запуск становится заметно быстрее.
Занимает 5–20 минут, всё это время телевизор будет подтормаживать — запускай
и оставь в покое.

**`--aggressive`** ограничивает число процессов «про запас» (`max_cached_processes=8`)
и отключает постоянную проверку интернета через серверы Google.
Плата — чуть более долгое переключение между приложениями.

## Откат: как вернуть всё назад

Скрипты пишут журналы в `reports/`, откат работает по ним:

```bash
./99_restore_tv.sh              # вернуть всё: и приложения, и настройки
./99_restore_tv.sh --packages   # только приложения
./99_restore_tv.sh --settings   # только настройки
./99_restore_tv.sh --all-system # аварийно: включить ВСЕ отключённые пакеты
```

На Windows — пункт **9** в меню `.bat`.

Крайний случай, если ничего не помогло: **Настройки → Сброс до заводских
настроек**. Все системные приложения вернутся — удаление через `--user 0`
физически APK из прошивки не стирает.

## Решение проблем

| Симптом | Причина и что делать |
|---------|----------------------|
| `failed to connect to 192.168.0.149:37765` | Порт изменился после перезагрузки ТВ — посмотри новый на экране отладки |
| `failed to authenticate` / `unauthorized` | Пропущено сопряжение по коду. Запусти `01_connect_tv.sh` заново |
| Сопряжение не проходит | ПК и ТВ в разных сетях (например, ПК по кабелю, ТВ в гостевом Wi-Fi), или в роутере включена изоляция клиентов (**AP isolation**) — выключить |
| Окно с кодом закрылось | Порт и код меняются каждый раз, открой заново |
| `Failure [not installed for 0]` | Приложение уже удалено — всё нормально |
| `Failure [... cannot be disabled]` | Вендор запретил отключение конкретно этого пакета. Скрипт такое просто пропускает |
| После чистки пропало нужное приложение | `./99_restore_tv.sh --packages` или пункт 9 в `.bat` |
| Чёрный экран вместо главного меню | Отключён лаунчер (скрипты этого не делают). `./99_restore_tv.sh --all-system` |
| Интернет работает, но приложения ругаются на сеть | Попробуй `./04_speedup_tv.sh --no-dns` и потом `settings put global private_dns_mode off` |
| Реклама всё равно осталась | Она внутри самого приложения (не сетевая). Помогает только удаление приложения |

## Частые вопросы

**Переживёт ли это перезагрузку?**
Да. И отключение пакетов, и настройки сохраняются в системе.

**А обновление прошивки?**
Обновление системы может вернуть часть приложений. Прогони скрипты заново.

**Нужен ли root?**
Нет. Всё работает через `--user 0` — штатный механизм Android.

**Можно ли окирпичить телевизор?**
Защищённый список закрывает всё критичное, а `--user 0` не трогает системный
раздел. Худший сценарий — сброс до заводских настроек.

**Сколько памяти освободится?**
Скрипты сами показывают «до/после» в мегабайтах. На типовом Android TV с
предустановленными витринами — обычно 150–400 МБ ОЗУ и заметно меньше
фоновой сетевой активности.

**Что даёт больше всего прироста?**
По убыванию: анимации (мгновенный эффект на глаз) → отключение Ассистента
(`katniss`) → отключение витрин VOD → `--compile` → `--aggressive`.

---

## Ещё две вещи, которые стоит сделать руками

1. **Отключить автообновление приложений**: Google Play → Настройки →
   Автообновление приложений → **Не обновлять**. Play обновляет приложения
   в фоне и в этот момент телевизор ощутимо тормозит.
2. **Отключить рекомендации на главном экране**: Настройки → Настройки
   устройства → Главный экран → выключить каналы и «Рекомендации приложений».
